# Archived implementations

`nanacoin_go/` is the original Go/TinyGo server and its earlier browser client.
It is retained for reference and possible future work, outside active builds,
tests, coverage, and deployment. Its Go module identity is unchanged.

The move preserves the implementation, local development files and history.
Historical scripts may assume the former repository layout; review their paths
before using them. The active server is `../nanacoin_rs/`, and the shared
Angular client is `../nanacoin_ui/`.
