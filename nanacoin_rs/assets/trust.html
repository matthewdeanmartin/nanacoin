Choose the connection that fits your household

Easy home mode lets everyone use HTTP without certificates. Secure household mode requires trusted HTTPS for everyone. Nana can switch to Secure mode after preparing the household devices.

iPhone / iPad

  1. Download the certificate in Safari and allow the profile download.
  2. Open Settings → Profile Downloaded (or General → VPN & Device Management). Install the certificate profile.
  3. Open Settings → General → About → Certificate Trust Settings and enable full trust for this CA. Its name may start with “mkcert”.
  4. Open secure NanaCoin below, sign in again, and save its bookmark for the child.
Apple's trust instructions

Android

  1. Download the certificate.
  2. In Settings, search for “Install a certificate”, select CA certificate, and choose NanaCoin-Home-CA.crt. Menu names vary; a screen lock may be required.
  3. Confirm after checking with Nana, then open the secure site in the browser.

Managed devices may prohibit user CAs. Native apps and WebViews may not trust user roots even if the browser does.

Open secure NanaCoin

If a warning remains, check the CA, full-trust setting, device clock and hostname. Browsers cannot install trust automatically. Do not enter passwords on this setup page: it accepts no logins or payments.

Once every device is ready, Nana opens Household → Connection security using HTTPS and enables Secure mode. Everyone is signed out to revoke old sessions. This cannot undo earlier HTTP exposure; change passwords if interception is suspected.

Remove trust later by removing the installed profile (iOS) or user CA (Android). If Nana gets locked out, the project includes an explicit USB recovery procedure—not a public HTTP downgrade switch.
